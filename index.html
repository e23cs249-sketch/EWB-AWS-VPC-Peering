THE PROJECT

Two networks. One private path.

A hands-on networking lab exploring how separate cloud networks can communicate without exposing application servers to the public internet.

✦ 01 / THE CHALLENGE

Connect without exposure

Two VPCs have separate private IPv4 ranges and need controlled communication—without public IP addresses on the application instances.

⌁ 02 / THE SOLUTION

Peer. Route. Control.

Configure VPC peering, routes in both directions, and security group rules that allow only the required traffic.

✓ 03 / THE OUTCOME

Private traffic verified

During the lab, SSH through the bastion and bidirectional ICMP connectivity between App-A and App-B were successfully tested.

ⓘ These are historical lab results. The AWS resources have since been cleaned up; this website is a project showcase, not a live AWS dashboard.

THE BUILDING BLOCKS

Cloud networking, made approachable.

Quick explanations of the ideas behind this project.

◈VPC isolationYour own logical network in AWS+

A Virtual Private Cloud is an isolated network space where you choose IP ranges, subnets, and traffic rules.

⌂Public vs. private subnetsDifferent routes, different exposure+

A public subnet has a route to an internet gateway. A private subnet does not provide direct inbound internet access to its instances.

⇄VPC peeringA private link between VPCs+

Peering lets two VPCs exchange traffic using private IP addresses, provided the CIDR ranges do not overlap and routes allow it.

↗Routes & return routesTwo-way directions matter+

Each subnet's route table needs a destination for the remote VPC CIDR via the peering connection. Both sides need routes.

⬡Security groupsStateful virtual firewalls+

Security groups control allowed inbound and outbound traffic for instances. Stateful rules allow response traffic for permitted connections.

⇢Bastion & SSH ProxyJumpA controlled jump point+

A bastion host provides an SSH entry point. ProxyJump forwards SSH through it to a private host without making that host public.

⌖Private IPv4Addressing inside networks+

Private IP addresses are used for communication within connected networks. They are not directly routable on the public internet.

◎ICMP pingA simple reachability check+

Ping sends ICMP Echo Requests and listens for replies. It helps verify a network path, but it does not prove every application port is reachable.
